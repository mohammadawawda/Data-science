# Data Science

Data science projects in Python: web crawling, text mining and network analysis.

* [books_crawler](books_crawler) a polite web crawler that collects about 4,000 books from bookdelivery.com, then cleans, sorts and summarizes the data.
* [text_mining](text_mining) text mining on Alice's Adventures in Wonderland: word frequencies, stopwords, stemming, POS tagging and a word cloud.
* [migration_networks](migration_networks) 30 years of international migration as networks: communities, hub countries, a gravity model and the effect of wars.
