# Text mining

Text mining on Alice's Adventures in Wonderland with NLTK.

* word frequencies and log log rank plots (Zipf's law)
* the same after removing stopwords and after stemming
* POS tagging, and a tagging mistake that the code finds by itself
* proper nouns and a word cloud
* a regex that finds repeated words

The code is in `code/` (how to run is in `code/README.txt`). The figures, tables and the report are in `output/`.
